# AI-Powered-Outlook-Assistant-for-Smart-Scheduling-Communication
An AI-powered assistant built with Microsoft Copilot Studio that processes natural language queries to manage Outlook Calendar and Email tasks like scheduling meetings, sending emails, and checking availability—boosting productivity through smart automation.


This project demonstrates a smart assistant built using Microsoft Copilot Studio, capable of handling natural language queries related to Outlook Calendar and email tasks such as:

-Checking schedules

-Rescheduling meetings

-Sending emails dynamically

Due to a known bug in front-end integration, the working demonstration is shown directly from Copilot Studio through a video.


📁 Repository Contents
File	Description
index.html	Frontend layout for the assistant UI
styles.css	Custom styles for layout and chat interface

🛠️ Features
AI-driven Copilot logic with intent recognition

Simulated frontend chat window with hardcoded replies for showcasing

Ability to respond to:

Scheduling queries

Calendar rescheduling

Busy checks

Future-ready JavaScript placeholders to plug real-time data via Power Automate & Microsoft Graph API

 How to Run Locally
Clone the repository:

git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
Open in Visual Studio Code (VS Code):

Right-click the folder → "Open with Code" (or open manually from VS Code)

Run the HTML file:

Simply open index.html in your browser.

Use Live Server extension in VS Code for a smoother experience.

Try Out the Chatbot Simulation:

Type messages like:

Reschedule my 11 AM meeting

What’s my schedule for May 10–18?

Am I busy tomorrow?

The assistant will reply based on preset logic.
